 RDKit Cheminformatics Project

A hands-on cheminformatics project I built while learning RDKit
from scratch. Covers molecular representations, property calculation,
drug-likeness filtering, fingerprints, and substructure searching —
the core toolkit for computational drug discovery.

## What This Project Is About

I used a set of embelin-derived Schiff base compounds as practice
molecules to learn RDKit workflows. The focus here is on the
cheminformatics skills — not the drug discovery project itself.
